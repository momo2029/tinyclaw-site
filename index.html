Features

Everything you need.
Nothing you don't.

TinyClaw runs on a single binary. No Docker, no Kubernetes, no cloud dependency. Just start it and go.

✉️

Multi-Account Email

Connect unlimited IMAP accounts. Read, search, and send emails through SMTP. Works with Gmail, Outlook, and any IMAP provider.

💬

AI Chat with Streaming

Chat with multiple AI providers. Streaming responses, tool invocation, and the ability to switch providers on the fly.

🔧

Extensible Skill System

OpenClaw-compatible skills. Drop a SKILL.md file and it just works. Skills are auto-injected into AI context for natural invocation.

🪶

Feishu / Lark Bot

WebSocket-based connection to Feishu. No public IP needed. Receive and reply to messages through your existing AI + tool chain.

🌐

Built-in Web UI

Setup wizard, dashboard, chat interface, skill management, and settings — all served by the binary itself. Alpine.js + Tailwind.

📦

Runs Anywhere

Raspberry Pi, old laptops, Android via Termux, low-end tablets. If it runs Linux/macOS/Windows, TinyClaw runs on it.

Performance

Built for the edge.
Runs on a potato.

Written in Rust with zero garbage collection overhead. Every byte counts.

terminal
# Build from source
$ cargo build --release

# That's it. One binary.
$ ls -lh target/release/tinyclaw
-rwxr-xr-x 1.7M tinyclaw

# Run it
$ ./tinyclaw
🦀 TinyClaw running on http://localhost:3000

# Memory footprint
$ ps -o rss= -p $(pgrep tinyclaw)
40960 # ~40MB
